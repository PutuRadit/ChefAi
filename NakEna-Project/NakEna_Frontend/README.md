# NakEna Frontend — Figma Replace Version

Folder ini mempertahankan struktur frontend lama dan template HTML tetap dipisah per halaman.

Isi utama:
- `app/`
- `templates/nakena/` untuk seluruh halaman HTML
- `static/assets/` untuk maskot dan gambar dari desain Figma

Cara mengganti:
1. Backup folder `NakEna_Frontend` lama.
2. Ekstrak folder `NakEna_Frontend` dari ZIP ini ke folder project yang sama.
3. Pilih Replace jika Windows meminta konfirmasi.
4. Jalankan backend seperti biasa.
